# Настройка сервера
## 10. Ansible
Управляющий узел работает на Fyvessa, в отдельном контейнере. Управляемый узел — гостевая Ubuntu 24.04 amd64 под QEMU. Управляющий контейнер разделяет только сетевое пространство с контейнером гипервизора. SSH на 127.0.0.1:2222 перенаправляется на порт 22 гостя, HTTP на 127.0.0.1:8080 — на гостевой Nginx:80. Внутри VM контейнер доступен на 127.0.0.1:5000.
Из каталога ansible выполните ansible-playbook -i inventory/bootstrap.ini site.yml под student. Для следующих запусков используйте ansible-playbook site.yml под devops. Исходный ключ student и отдельный ключ devops хранятся у контроллера. Включена сверка ключа хоста.
Роли base, ssh, nginx и app устанавливают Docker, настраивают ключи, прокси и контейнер. Исходный образ ghcr.io/darkness6030/devops-ci-app:39519e8ed47438802576f2f186e58261f25da36e. Для контроля используйте ansible-playbook verify.yml и curl --fail http://127.0.0.1:8080/health.
